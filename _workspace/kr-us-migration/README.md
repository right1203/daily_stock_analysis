# KR+US Migration Workspace

이 디렉토리는 KR+US 마이그레이션 하네스의 중간 산출물을 보관한다.

## Layout

- `00-charter.md`: 범위, 성공 기준, 금지 사항
- `01-audit/`: 중국 표면적 인벤토리와 파일 소유권 맵
- `02-handoffs/`: 워커별 변경 요약과 후속 작업 메모
- `03-validation/`: 트리거 테스트와 검증 체크리스트
- `04-report/`: 최종 보고서

## Naming Rules

- 감사 파일은 명사형 이름을 사용한다.
- 핸드오프 파일은 담당 영역 이름을 사용한다.
- 보고서 파일은 실행 결과와 남은 리스크를 함께 적는다.

## Operating Rules

- 긴 내용은 파일에 남기고 메시지는 요약만 전달한다.
- 메인 에이전트만 핸드오프를 중재한다.
- 더티 워크트리와 충돌하는 파일은 차터와 ownership map에 먼저 기록한다.
